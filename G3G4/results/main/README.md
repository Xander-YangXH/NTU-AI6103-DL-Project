# results/main/ — 主实验结果（26 个运行，官方 validation）

报告中 G3 与 G4 的对比数据全部来自这里。

- 学习率：每个 (组, 任务) 使用 tune 阶段选定的学习率，见 `results/chosen_lr.json`。
- 种子：SST-2 0–2，MRPC / RTE 0–4。
- 评估集：官方 GLUE validation，在报告中作为测试集。
- Slurm 作业 48270，用时 54 分钟；日志见 `logs/main_*.log`。
- 文件名为 `main_<组>_<任务>_lr<lr>_s<seed>.json`。

## 参数量与用时

| 组 | SST-2 参数（相对预算） | MRPC | RTE | 平均总用时 SST-2 / MRPC / RTE |
|---|---|---|---|---|
| G3 | 1,267,200（−4.5%） | 1,258,906（−5.1%） | 1,246,925（−6.0%） | 436 / 139 / 143 s |
| G4 | 1,326,592（−0.0%） | 1,326,797（−0.0%） | 1,326,950（−0.0%） | 451 / 210 / 223 s |

- G3 的预算单位是“秩的个数”（576 个），所以实际参数量比预算少约 5%。
- G4 按参数预算分配，偏差都在 ±0.1% 以内。
- G4 用时更长，主要来自初始化时额外计算解释方差（34–103 s）。seed 0 复用了 tune 阶段的缓存，所以初始化不到 1 s，总用时也明显更短。
- 峰值显存 1.3–2.4 GB。
