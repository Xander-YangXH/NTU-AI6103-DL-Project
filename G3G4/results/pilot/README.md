# results/pilot/ — 试跑结果（4 个运行，dev 集）

pilot 是正式调参前的试跑。

- 设置：lr 5e-4（网格中值）、seed 0，在 dev（train 的 10%）上评估。
- 目的：确认整条流水线在 TC2 上能跑通，并估算每个运行的用时，以便安排后续作业。
- Slurm 作业 48246，用时 8 分 56 秒；日志见 `logs/pilot_*.log`。

| 文件 | 组 | 任务 | dev primary | LoRA 参数 | 用时 |
|---|---|---|---|---|---|
| `pilot_G3_sst2_lr0.0005_s0.json` | G3 | SST-2 | 95.00 | 1,264,896 | 488 s |
| `pilot_G3_mrpc_lr0.0005_s0.json` | G3 | MRPC (F1) | 91.18 | 1,251,072 | 139 s |
| `pilot_G3_rte_lr0.0005_s0.json` | G3 | RTE | **48.19** | 1,246,464 | 143 s |
| `pilot_G4_rte_lr0.0005_s0.json` | G4 | RTE | 65.86 | 1,326,336 | 219 s |

## 说明

- G3 RTE 停在 48.19%，也就是全部预测为多数类，说明训练在这个学习率下塌缩了。
- tune 阶段确认这是学习率问题：RTE 在 2e-4 下正常（G3 79.1、G4 77.5），在 5e-4 / 1e-3 下塌缩。因此 main 阶段 RTE 使用 2e-4，main 中没有出现塌缩。
- pilot 结果不参与选择。它与 tune 中配置相同的运行（lr 5e-4、seed 0）结果一致到 0.1 分，可以作为重复性的旁证。
