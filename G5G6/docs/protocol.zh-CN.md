# 共享配置与 G5/G6 校准

训练、选参、数据划分与低资源设置见[配置](../results/protocol.json)和[说明](../README.md)。G5 按 rank 数量分配，G6 按参数成本分配。重分配后 alpha/r 保持 1，LoRA dropout 为 0。

梯度加权校准保留标签，用有效 token 的输出梯度范数加权输入激活。使用最多 1024 个训练样本、batch 16、rho=2 和 0.99 子空间相似度阈值记录收敛信息。固定样本预算结束时，各层可能尚未收敛。低资源训练的校准最多使用该训练子集的 1000 个样本。

逐次截断的流式 SVD 近似全量分解。单 token 加权统计不包含序列梯度的跨 token 交叉项。初始化时间包含共享校准和各组的独立适配器构建。每轮记录训练第一步更新前的 B 梯度范数、前 500 步 loss、显存及耗时。
