## 2. Findings so far

1. **On the full-data tasks, no initialisation beats plain LoRA significantly.** G2, G3 and G4 are all within ±0.9 points of G1, and every interval contains 0. G3 (EVA) has the highest mean on SST-2 and MRPC, but the margin is smaller than the seed noise, especially on RTE.
2. **A larger initial gradient does not translate into accuracy.** The step-0 gradient on B grows by more than an order of magnitude from G1 to G3/G4 and G7, yet accuracy barely moves. Matching EVA's row norm (G2) alone changes nothing (magnitude), and EVA's directions (G3) add a 4–9× larger gradient at the same norm but only a non-significant gain (direction).
3. **G7 (LoRA-GA) is unstable on RTE.** It matches the others on SST-2 and MRPC but averages 56.68 on RTE, with seed 1 predicting one class for all 277 examples; the drop against G1 and G3 is significant. All three G7 tasks selected lr 2e-4 on seed 0 only, which did not protect against this.
4. **Low resource: EVA is significantly worse than plain LoRA, and this is not a learning-rate effect.** By the shared rule G1 used 5e-4 and G3 1e-3 (G1 91.44 vs G3 88.81). Re-running G1 at 1e-3 (5 seeds) gives 91.47 ± 0.66, unchanged, and at equal lr G3 − G1 = −2.66 [−3.22, −2.11]. This runs against H2's premise that spectral initialisation helps most with little data.
5. **Calibrating EVA on another task (G9) costs nothing measurable.** G9 − G3 is +0.87 [−3.31, +5.04] on RTE (calibrated on MRPC), −0.52 [−1.21, +0.17] on MRPC (calibrated on RTE) and −0.19 [−1.63, +1.24] on SST-2 (calibrated on MRPC); none is significant. For H4 this points to the failure branch: the activation subspace is mostly fixed by the pretrained model, so task information would have to enter through label gradients. That is GW-EVA's motivation, but it only holds if H1 shows that Σ_g's subspace actually differs from EVA's.
6. **H2 cannot be tested yet.** G5/G6 are the only GW-EVA runs and follow an independent protocol (see §3). Testing H2 needs G5 under the shared protocol, paired with G3 and G1, including the low-resource run, where EVA currently trails LoRA.

## 3. G5 / G6: independent protocol

The `hanyanze` runs differ from the shared protocol in max length (512 vs 128), epochs (RTE / MRPC / SST-2 80 / 30 / 10 vs 10 / 10 / 3), final training on the full train set rather than 90%, a different split and learning-rate grid (including 1e-4) and an LR selection rule of mean(acc, F1). Every JSON carries `shared_protocol_compliant = False`. The author states they must not be paired with G3/G4/G7, so they are reported separately:

| Task | G5 | G6 |
|---|---|---|
| SST-2 (acc) | 93.92 ± 0.23 | 93.43 ± 0.73 |
| MRPC (F1) | 91.37 ± 0.95 | 91.68 ± 1.17 |
| RTE (acc) | 78.84 ± 2.00 | 78.84 ± 0.91 |

The higher RTE score is not evidence for GW-EVA: with 8× the epochs and longer inputs, a plain-LoRA baseline under the same protocol is needed before any comparison.

## 4. Comparability caveats

| Item | Groups affected | Effect |
|---|---|---|
| GPU | G3/G4 on A40; G1/G2/G7 on L40S; G9 on an RTX 3050 Ti laptop GPU | Wall-clock times are not comparable across these groups; accuracy should be unaffected up to bf16 nondeterminism |
| Software versions | G7 uses torch 2.4.0 / transformers 4.52.4 / peft 0.17.1; G1–G4 use 2.11.0 / 5.21.0 / 0.21.2; G9 uses transformers 5.20.2 | Same algorithm and split, but not bit-identical numerics |
| Parameter count | G3 uses 1.24–1.28 M LoRA parameters (−3.8% to −6.4%), by design of EVA's rank-count budget; G9 1.24–1.27 M (−4.5% to −6.4%) | Reported, not corrected |
| Protocol | G5/G6 | Not pairable (§3) |
| Learning rate | Low-resource G1 vs G3 | Ruled out by a same-lr control (§2.4) |
