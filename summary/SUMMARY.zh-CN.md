## 2. 目前的发现

1. **在完整数据的三个任务上，没有任何初始化显著优于普通 LoRA。** G2、G3、G4 与 G1 的差距都在 ±0.9 分以内，置信区间都包含 0。G3（EVA）在三个任务上的均值都最高，但领先幅度小于种子间的波动，RTE 上尤其如此。
2. **初始梯度更大，并不能转化为精度。** 从 G1 到 G3/G4 和 G7，第 0 步 B 的梯度增大了一个数量级以上，精度却几乎不变。只把行范数提到与 EVA 相同（G2，即幅值）毫无作用；在相同行范数下，EVA 的方向（G3）让梯度再大 4–9 倍，但精度提升不显著。
3. **G7（LoRA-GA）在 RTE 上不稳定。** 它在 SST-2 和 MRPC 上与其他组相当，但 RTE 平均只有 56.68，其中 seed 1 对全部 277 个样本都预测为同一类；相对 G1 和 G3 的下降都显著。G7 三个任务都在 seed 0 上选中了 2e-4，这个选择没能避免塌缩。
4. **低资源下 G1 比 G3 高 2.6 分，但有学习率混淆。** 按共享规则，各组沿用自己在完整 SST-2 上选出的学习率（G1 为 5e-4，G3 为 1e-3）。同学习率对照（G1 用 1e-3，5 个种子）已在集群上排队；结果出来之前，这一条不应当作关于 EVA 的证据。
5. **H2 目前还无法检验。** GW-EVA 只有 G5/G6 的运行，而它们用的是独立协议（见第 3 节）。要检验 H2，需要在共享协议下跑 G5，并与 G3 配对，最好也跑低资源实验。

## 3. G5 / G6：独立协议

`hanyanze` 分支的运行与共享协议有以下不同：

- 最大长度 512（共享为 128）；
- 训练轮数 RTE / MRPC / SST-2 为 80 / 30 / 10（共享为 10 / 10 / 3）；
- 最终在完整训练集上训练，而不是 90%；
- 数据划分和学习率网格不同（包含 1e-4）；
- 选参规则为 mean(acc, F1)。

每个 JSON 都标有 `shared_protocol_compliant = False`，作者也说明不能与 G3/G4/G7 配对，因此单独列出：

| 任务 | G5 | G6 |
|---|---|---|
| SST-2 (acc) | 93.92 ± 0.23 | 93.43 ± 0.73 |
| MRPC (F1) | 91.37 ± 0.95 | 91.68 ± 1.17 |
| RTE (acc) | 78.84 ± 2.00 | 78.84 ± 0.91 |

RTE 分数更高并不能作为 GW-EVA 有效的证据：训练轮数是 8 倍、输入也更长，比较之前需要先有同一协议下的普通 LoRA 基线。
