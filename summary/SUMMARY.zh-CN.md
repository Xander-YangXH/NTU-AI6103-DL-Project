## 2. 目前的发现

1. **在完整数据的三个任务上，没有任何初始化显著优于普通 LoRA。** G2、G3、G4 与 G1 的差距都在 ±0.9 分以内，置信区间都包含 0。G3（EVA）在 SST-2 和 MRPC 上的均值最高，但领先幅度小于种子间的波动，RTE 上尤其如此。
2. **初始梯度更大，并不能转化为精度。** 从 G1 到 G3/G4 和 G7，第 0 步 B 的梯度增大了一个数量级以上，精度却几乎不变。只把行范数提到与 EVA 相同（G2，即幅值）毫无作用；在相同行范数下，EVA 的方向（G3）让梯度再大 4–9 倍，但精度提升不显著。
3. **G7（LoRA-GA）在 RTE 上不稳定。** 它在 SST-2 和 MRPC 上与其他组相当，但 RTE 平均只有 56.68，其中 seed 1 对全部 277 个样本都预测为同一类；相对 G1 和 G3 的下降都显著。G7 三个任务都在 seed 0 上选中了 2e-4，这个选择没能避免塌缩。
4. **低资源下 EVA 显著差于普通 LoRA，且不是学习率造成的。** 按共享规则 G1 用 5e-4、G3 用 1e-3（G1 91.44 对 G3 88.81）。G1 改用 1e-3 再跑 5 个种子，得到 91.47 ± 0.66，几乎不变；同学习率下 G3 − G1 = −2.66 [−3.22, −2.11]。这与 H2 的前提（谱初始化在小数据上收益最大）相反。
5. **用别的任务校准 EVA（G9），没有可测的损失。** G9 − G3 在 RTE（用 MRPC 校准）上为 +0.87 [−3.31, +5.04]，MRPC（用 RTE 校准）上为 −0.52 [−1.21, +0.17]，SST-2（用 MRPC 校准）上为 −0.19 [−1.63, +1.24]，都不显著。对 H4 来说，这指向“失败”分支：激活子空间主要由预训练模型决定，任务信息只能通过标签梯度进入。这正是 GW-EVA 的动机，但前提是 H1 证明 Σ_g 的子空间确实与 EVA 不同。
6. **H2 目前还无法检验。** GW-EVA 只有 G5/G6 的运行，而它们用的是独立协议（见第 3 节）。要检验 H2，需要在共享协议下跑 G5，与 G3、G1 配对，并且包括低资源实验（目前 EVA 在那里落后于 LoRA）。

## 3. G5 / G6：独立协议

`hanyanze` 分支的运行与共享协议有以下不同：

- 最大长度 512（共享为 128）；
- 训练轮数 RTE / MRPC / SST-2 为 80 / 30 / 10（共享为 10 / 10 / 3）；
- 最终在完整训练集上训练，而不是 90%；
- 数据划分和学习率网格不同（包含 1e-4）；
- 选参规则为 mean(acc, F1)。

每个 JSON 都标有 `shared_protocol_compliant = False`，作者也说明不能与 G3/G4/G7 配对，因此单独列出：

| 任务 | G5 | G6 |
|---|---|---|
| SST-2 (acc) | 93.92 ± 0.23 | 93.43 ± 0.73 |
| MRPC (F1) | 91.37 ± 0.95 | 91.68 ± 1.17 |
| RTE (acc) | 78.84 ± 2.00 | 78.84 ± 0.91 |

RTE 分数更高并不能作为 GW-EVA 有效的证据：训练轮数是 8 倍、输入也更长，比较之前需要先有同一协议下的普通 LoRA 基线。
