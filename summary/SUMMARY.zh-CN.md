## 2. 发现

1. **GW-EVA 没有优于 EVA（H2 不成立）。** 共享协议下 G5 − G3 在 SST-2、MRPC、RTE 和低资源上分别为 −0.15、−0.88、−1.23 和 −0.46 分，区间都包含 0，而且均值都略为负。H2 只有第 0 步那部分成立：GW-EVA 第 0 步 B 的梯度是 EVA 的 1.3–2.1 倍（例如 MRPC 上 3.36 对 1.63）。H2 关于早期训练的另一半（前 500 步 loss 更低）在同学习率下不成立：G5 与 G3 在每个任务的前 50 步都没有差别，SST-2 上之后 G5 的 loss 反而略高（+0.02，显著）。
2. **完整数据上，没有任何初始化优于普通 LoRA。** G2–G6、G8 和 G9 在每个任务上与 G1 的差都在 ±1.9 分以内，区间都包含 0。这八个组在 SST-2 和 MRPC 上最好与最差之间相差不到 1.2 分，比 RTE 上的种子波动还小。
3. **感知数据的初始化在早期拟合更快，但优势不能保持。** MRPC 上各组学习率都是 2e-4，EVA、GW-EVA、LoRA-GA 在前 500 步的训练 loss 都显著低于普通 LoRA（第 1–50 步低 0.014–0.024，第 51–200 步低约 0.055），但最终 F1 没有显著差别。只匹配幅值（G2）对 loss 的影响最多 0.004。
4. **初始梯度更大，并不能转化为精度。** 从 G1 到 G3–G7，第 0 步梯度增大了 7–37 倍。用随机方向匹配 EVA 的行范数（G2）毫无作用；同样行范数下，EVA 的方向（G3）让梯度再大 4–9 倍，GW-EVA（G5）又大 1.3–2.1 倍，而精度始终持平。G8 在 MRPC、RTE 上的第 0 步梯度甚至比 G3 大 1.4–1.7 倍，精度却略低。
5. **数据少时 EVA 差于普通 LoRA：大部分差距来自学习率，其余来自 EVA 的方向。** 按共享规则（低资源沿用完整 SST-2 上的学习率），G3 比 G1 低 2.64 分，而 G1 本身对学习率不敏感（5e-4 和 1e-3 结果相同）。EVA 却很敏感：在同一张显卡上，G3 的学习率从 1e-3 降到 5e-4、2e-4，结果从 89.50 升到 90.55、90.87，所以共享规则恰好给了 EVA 最差的设置。即便在它最好的学习率下，EVA 仍比 G1 低 0.57 [−1.10, −0.05]，差距小但显著。保留 EVA 的方向、去掉秩重分配（ρ = 1，参数量正好等于预算）不改变结果（−0.41 [−2.32, +1.50]），所以剩下的差距来自方向。lr 1e-3 下的 loss 曲线说明了机制：EVA 和 GW-EVA 起步时与 LoRA 持平，随后在第 51–200 步拟合训练集更慢（分别 +0.09 和 +0.15，显著），是优化问题，不是过拟合。之前“差距不是学习率造成的”这一说法是错的：G1 的对照只说明 G1 不依赖学习率。
6. **按参数成本分配秩（H3）在完整数据上没有作用。** G4 − G3 和 G6 − G5 在 SST-2、MRPC、RTE 上都不显著。唯一显著的低资源 G6 − G5 = +1.53 很可能来自学习率（见脚注 2）；低资源下 EVA 用 ρ = 1 和 ρ = 2 也没有差别，同样看不到分配的作用。
7. **RTE 的训练本身就脆弱，LoRA-GA（G7）是最严重的。** G7 在 RTE 上平均 56.68，比 G1 低 17.3 分且显著：seed 1 对全部 277 个样本预测为同一类，seed 2、3 也接近随机；SST-2 和 MRPC 上与其他组相当。但单类塌缩不是 LoRA-GA 独有的：补到 10 个种子后，普通 LoRA（G1，lr 5e-4）的种子 8 也塌缩了（52.71，训练 loss 一直停在 ln 2）；调参时 7 个组里有 6 个在 RTE dev 上用 1e-3 塌到 48%。G7 的区别在程度：它 5 个种子都低于 67，而 G1 的 10 个种子里有 9 个高于 70。所以报告 RTE 时应同时给出塌缩率，而不只是均值。
8. **校准数据来自哪里几乎无关紧要（H4）。** 用别的任务（G9）或通用的 wikitext-103 文本（G8）校准 EVA，在完整数据上都不显著好于或差于普通 LoRA。与用本任务数据校准的 EVA（G3）相比，唯一显著的差是 G8 在 MRPC 上的 −0.91 [−1.54, −0.28]（G8 方差很小，而且这里约 20 个比较都没做多重比较校正）；G8 在 MRPC 上的早期拟合也略慢（loss 高 0.007–0.015）。子空间本身的差别大得多：G8 与 G3 的重合度为 0.64–0.72，G9 为 0.49–0.66。G8 保留了 G3 的 token 排布、只换了文字，重合度反而高于同时换了任务和格式的 G9；差距主要在 SST-2 上，那里 G9 的校准数据从单句变成了句对，所以之前以为是“任务内容”的部分差异，可能来自输入格式。结合第 1–4 条，这说明在 RoBERTa-base、r = 8 的设置下，精度对 A 从哪些方向出发并不敏感。
9. **低资源下，单个种子的结果依赖显卡，均值不依赖。** 用相同的代码、版本和种子把 G3 从 A40 换到 L40S 重跑，单个种子最多变化 2.5 分（第一步训练 loss 就已不同，来自分类头预热的 bf16 数值差异），5 个种子的均值只变了 +0.69（不显著）。所以低资源下跨显卡的种子配对较弱：G8 比 G3 高的 +1.08，换成同显卡的复现结果后只剩 +0.39。

### 假设检验情况

| 假设 | 结论 | 依据 |
|---|---|---|
| H1：Σ_g 的子空间不同于激活协方差的子空间 | **未测量** | 所有分支都没有 GW-EVA 与 EVA 子空间的重合度 |
| H2：GW-EVA 的第 0 步梯度更大、早期 loss 更低、精度高于 EVA | **不成立** | 只有第 0 步梯度更大；早期 loss 相同或略高，精度不显著且均值略为负（第 1 条） |
| H3：按成本分配会改变结果 | **不成立** | 完整数据上 G4 − G3、G6 − G5 都不显著；低资源 G6 − G5 很可能来自学习率，均匀秩的 EVA 与 ρ = 2 相同（第 5、6 条） |
| H4：任务输入有多特异 | **就精度而言已回答** | 本任务数据、别的任务和通用文本给出相同的精度；子空间重合度 0.49–0.72，且可能更多取决于输入格式而非内容；还缺同任务的噪声基线（第 8 条） |

按 [`NEXT_STEPS.zh-CN.md`](NEXT_STEPS.zh-CN.md) 里的决策表，结果指向**分析型 / 负结果**的论文主线：在这些任务上，感知数据的 LoRA 初始化（EVA、GW-EVA、LoRA-GA）大幅改变了早期梯度，也加快了早期拟合，但最终精度不变；在低资源下，它们需要比 LoRA 更低的学习率，而且仍略差。属于“子空间不同”还是“子空间几乎相同”的分支，仍取决于 H1。
